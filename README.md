# Christopher Owens Portfolio

A personal portfolio built with Next.js to present Christopher Owens's background, skills, selected projects, professional experience, and contact information. The site focuses on cloud infrastructure and platform engineering, with project work spanning Azure, Terraform, automation, and web development.

## Technology

- Next.js App Router, React, and TypeScript
- Tailwind CSS
- Radix UI components and Lucide icons
- Framer Motion for animation

## Development

The project provides dev, lint, build, and start scripts in package.json. The current package-lock.json needs to be synchronized with package.json before npm ci can install dependencies successfully.
